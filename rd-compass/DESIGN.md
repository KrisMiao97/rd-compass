# 研发罗盘输出设计规范

更新：2026-11-13。适用于研发机会、路线比较与立项准备报告。

## 方向与读者

- 以可阅读的技术研究文档为主体，首屏呈现与本次研究目的有关的发现及条件判断；不以操作指令或方法介绍开场。（用户确认）
- 负责人先判断机会，工程师再读机制和取舍，资料复核者可回查原文；三种需要通过阅读层级满足，不在每句话里同时解释所有背景。（用户确认）
- 正文采用蓝白底色、深色文字、细线分隔与紧凑目录，减少大面积海报和装饰卡片。（沿用现有报告；Agent 推断）

## 品牌资产

- 名称固定为“研发罗盘”，无新增商业标志。（用户确认）
- 不强制产品照片或生成图片；技术图承担结构、位置和动作解释，不承担气氛营造。（Agent 推断）

## 唯一实现入口

- 共享样式与交互位于 `assets/report.html`；生成器为 `scripts/render_report.py`，数据说明为 `references/output-format.md`。（Agent 推断）
- 文字底稿使用 `assets/report-outline.md`。JSON 负责数据与引用，模版负责表现；报告不再复制一套个案专用渲染代码。（Agent 推断）
- 现有玻璃空气炸锅报告是内容与案例参照，新模版另交示范页，不自动替换已经交付的报告。（Agent 推断）

## 阅读顺序

按模式选择，不固定一套顺序：

- 技术理解与演进：简短发现、产品背景和问题、已知时间变化、当前技术格局、现有路线的工作过程与发展；组合机会探索时再给后续方向。
- 研发机会探索：简短背景、候选机会与比较、所依赖的现有路线、推导与条件；有用时再补时间记录。
- 路线比较与立项准备：目标与约束、方案比较和取舍依据、必要的验证计划。计划不是其他模式的必填模块。

现有路线与未来方向分别命名。章节缺乏材料时说明具体未知或省略不适用模块，不能造空洞内容凑齐。证据索引和逐件记录分别展示；计数就近注明单位，避免多个不同分母的数字并排暗示可相减。

## 语义角色

变量定义以模版代码为准，不在其他文件另建色值表。（Agent 推断）

- `--paper` 与 `--wash`：正文承载面和页面背景。（Agent 推断）
- `--ink` 与 `--muted`：主要内容和来源等次级文字，次级文字仍需清楚可读。（Agent 推断）
- `--accent` 与 `--tint`：导航、核心判断、证据入口及比较推断的浅色背景，不表示投入优先。（Agent 推断）
- `--hypothesis`：尚存假设的背景；必须同时写出文字角色，不只靠颜色辨认。（用户确认）
- `--line` 与 `--radius`：分组边界，不把所有段落做成独立卡片。（Agent 推断）
- `--body` 与 `--small`：正文与辅助文本；中文正文不小于 15px，关键限制与图中文字不小于 13px。长段控制行宽，手机不以缩字适配。（Agent 推断）
- `--space` 与 `--motion`：间距和轻微状态反馈。无入场遮挡、自动轮播或视差；减少动效模式关闭过渡。（Agent 推断）

## 组件与状态

- 首屏结论区放与本次研究目的有关的发现和条件判断；“证据不足”不能代替分析成果。（用户确认）
- 比较表在桌面同时展示全部字段，长判断列获得更多宽度；窄屏按同一字段比较所有方向，默认显示当前判断，并允许切换。（Agent 推断）
- 方向名与 D 编号在全部位置一致；证据状态、决策阶段分别标注，编号不兼作优先级。（用户确认）
- 五步论证保留角色锚点，标题写本步的具体结论；“可能能力”与“尚存假设”有清楚的文字区别。（用户确认）
- 机制图贴近材料披露与方案差异，后续能力、条件与假设使用整行，避免图下出现大块空白。图注说明部件、动作及概念范围；依赖尚未取得附图的细节不补画。图不是专利原图时不能伪装成原图。小屏保留图的可读尺寸，允许键盘与触屏横向查看，图注始终完整显示。（用户确认）
- 时间图按实际事件日期定位节点，明确公开、授权、产品或资料日期类型，节点写明具体做法和证据，不默认画成单线演进或继承关系。（用户确认）
- 证据条目摘要不折叠；详情记录公开号或资料标识、原文位置、来源角色及是否进入统计。（用户确认）
- 证据入口点击后定位并展开目标条目；筛选不应让该条目无法到达。空结果说明状态并提供重置。（Agent 推断）
- 打印展开全部详情并恢复全部证据，打印结束恢复原筛选与展开状态。（用户确认）
- 下载真实内嵌研究数据；无已接入功能不做假按钮，外部来源与内部详情入口分开。（用户确认）

## 内容不能被压缩掉的部分

- 材料实际披露、不同方案差异、可能能力、成立条件、剩余假设均需完整句子，不用术语堆叠替代说明。（用户确认）
- 改变判断的材质、作用位置、实施例与工况限定紧跟结论；检索式、计数规则等查证细节可以放后面。（用户确认）
- 首屏数量同时给出统计对象和日期；图旁给分母和计数单位。没有核实的数据不补数字。（用户确认）
- 研究建议说明为什么值得考虑；试验或资料请求说明何种答案改变取舍，不能让读者代替分析者完成分析。（用户确认）

## 验收

- 检查 1440、1100、950、700、390 像素宽度；首屏能读到与本次阅读目的相符的发现，中间宽度没有缩小到看不清的示意图。（沿用本轮验证；Agent 推断）
- 方向、证据和时间节点数量由输入决定；至少验证少量与多个方向，无方向时如实呈现发现及边界。（Agent 推断）
- 检查键盘焦点、筛选与重置、证据跳转、下载、离线打开、完整打印、打印后恢复。（Agent 推断）
- 关键文字达到常规正文对比度；真实截图审阅与交互验证分别记录，不能用静态源码检查替代。（Agent 推断）
- 不把界面评审当作独立研发或专利复核。（用户确认）

内容验收按 references/reader-review.md 执行；浏览器检查不能代替内容审阅。对于 schema 2，技术模式不显示无关的决策阶段；目录与实际渲染章节一致。
