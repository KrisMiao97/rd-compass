# 研究内容与读者验收

记录被审数据版本、实际审阅范围和意见；未给原文的审阅只能检查报告内部，不冒称独立原文复核。

## 读者能获得什么

- 技术理解：读者能否解释产品问题、结构用途及关键路线差别？不要求读者先有机构知识。
- 机会探索：能否解释拟改变什么能力、为什么值得研究、适用条件和代价？不把专利归类自动当机会。
- 决策准备：目标与约束是否明确，比较是否相称，条件如何改变取舍？需要验证计划时再检查可执行性。

## 重点内容复核

1. 关键机制能否讲清位置、连接、作用条件、实际方向、结果和必要的复位？静态项可不适用，未知项说明影响，不机械强填字段。
2. 时间节点的类型和所述内容是否一致？更早文本是否确实披露该机制？先后、继承、替代与采用是否分开？
3. 关键陈述是否对应同件版本和具体位置？同一手册多个段落不得用一处定位冒充全部依据。
4. 原始披露、申请人效果宣称、商品采用、比较推断和实测是否混用？研究优先、基准与性能优越是否区分？
5. 表内外、申请与版本、阅读与复核、卡片关联是否一致？读者能否找到实际范围与完整清单？
6. 读者理解是否依赖跨多个页面自行拼出关键动作？正文先解释，关键限定不能只藏在卡片。

## 审核意见的处理

每条意见包含位置、问题、影响、依据、判断类型（正文可判／需原文核实／材料不足）和采纳状态。原文核实前不把审阅者推断写成事实。不同模型意见不靠投票采纳；模型审阅也不能替代真实读者试读。没有明确调用授权时不运行其他模型。

源材料变化后更新单篇记录及受影响专题、图注、日期和卡片，再生成全部派生文件。只改正文不改状态不算完成。程序能发现断链与文件版本冲突，不能证明机制正确或研究全面。

## 回归案例

- 水壶案例仅作为真实问题来源：检查产品背景、拨片与释放的完整过程、较早公开与授权区别、补读后清单同步。未重新读取真实材料不能声称完成事实复审。
- 合成过滤案例：一张卡关联两个版本，两卡关联同一记录，阅读与复核重叠仍合法；无时间线和无候选方向也可合法。
- 静态隔热结构：不编造触发和复位；历史未知时保留结构比较。
- 明确的试验计划请求：允许有步骤与指标，不因禁止默认教人做事而删掉用户所需计划。
- 局部阅读：只覆盖约定片段，不能标为整篇精读；旧 schema 1 可继续读取但不能假称已通过新版记录检查。

自动测试见 tests，真实页面检查另行记录。验收记录不使用准确率或已读条数替代上述认识。
