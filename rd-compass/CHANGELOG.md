# 更新记录

## 0.4.0 · 2026-11-13

- 根据技术理解、机会探索、决策准备选择阅读结构，保留局部研究。
- 现有路线与候选方向分别建模，明确研究优先、比较基准与性能比较的依据。
- 新 schema 2 支持阅读和复核分别记录、多对多证据关联、事件日期类型和多点原文定位；兼容 schema 1。
- 同源生成主报告、逐件页、CSV、数据和内容指纹清单，可检查成果是否混用旧版本。
- 增加内容与目标读者验收；结构校验、事实复核和浏览器检查分别记录。
- 合成案例覆盖静态结构、无历史、无方向、明确计划、日期未知、补读同步与来源定位；不将水壶具体路线写成通用规则。
