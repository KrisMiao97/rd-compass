# 水壶专利演示｜清理滤件前，要先打开壶盖吗？

比较两件公开专利。假设同样要清理壶嘴附近的滤件，分别看壶盖必须保持原位和允许打开壶盖时，两种结构能怎样取出滤件。

<details>
<summary><strong>路线一｜从壶嘴上方取出滤件</strong></summary>

**US5672274A** 的滤件装在壶嘴处，两侧插入固定连接框架的槽内。倒水时，水经过框架的开口和滤网，再从壶嘴流出。维护时，从壶嘴上方握住滤件顶缘向上拉，滤件底部凸起脱离锁止位置，连接框架留在壶体上。壶盖可以保持原位。

核查位置为权利要求 1、4、7、11–13 和图 2、3、4A、4B。 [专利原文](https://patents.google.com/patent/US5672274A/en) · [附图 PDF](https://patentimages.storage.googleapis.com/5e/6a/87/d830815951b129/US5672274.pdf#page=3)

</details>

<details>
<summary><strong>路线二｜打开壶盖，滤件随盖移开</strong></summary>

**EP0676161A1** 的滤件由壶盖支承。合上壶盖时，滤件周缘与壶嘴附近的内壁接合。倒水时，朝向壶嘴的水经过滤件后流出。打开壶盖时，滤件离开接合位置。在本文讨论的可拆实施例中，开盖后可将滤件从盖上拆下。

核查位置为权利要求 1、4、7–9 和图 2、9。 [专利原文](https://patents.google.com/patent/EP0676161A1/en) · [附图 PDF](https://patentimages.storage.googleapis.com/54/2b/18/0fc0cdc6603a21/EP0676161A1.pdf#page=6)

</details>

<details>
<summary><strong>同一维护任务下，两条路线怎么选？</strong></summary>

| 使用条件 | 从两件公开专利可得到的判断 |
| --- | --- |
| 必须保持壶盖原位 | US5672274A 的取件动作符合这个条件。EP0676161A1 所比较的实施例通过开盖移出滤件。 |
| 允许先打开壶盖 | 两种取件路径都可以纳入比较。可继续关注取件空间、接触部位及取出后的清洗动作。 |

案例只核查两件文献的相关部分。清洗耗时、过滤效果和寿命需要同等工况下的测量。

</details>
