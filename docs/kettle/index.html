取出水壶滤件，需要先打开壶盖吗？

研究发现：两件专利把滤件分别连接在壶嘴附近的固定框架和壶盖上。连接位置不同，取出或接近滤件时需要移动的部件也不同。

产品机会：比较独立取出滤件与随开盖接近滤件两种维护方式，为目标产品选择合适的连接结构。

条件判断：若维护时不能移动壶盖，优先研究从壶嘴侧单独取出滤件的结构。若允许开盖，两条路线都保留，再比较握持和取出空间、开合路径及复位要求。

本例仅定点核查 US5672274A、EP0676161A1 的相关权项、实施段与必要附图；未调查用户、未做样机或寿命试验，未进行法律状态或实施自由分析。 当前证据支持比较结构和维护动作，清洗效果和寿命仍缺少可比数据。

滤网要拦住杂质，连接结构还要允许维护

倒水时，壶内的水经过壶嘴附近的滤网后流出；滤网用于拦截水垢等杂质。取出滤件时，滤网如何固定、手从哪里接近、哪些部件需要先移动，就决定了维护动作。下面比较两种连接方式，并将结构事实与目标用户的实际需要分开。

现有技术路线与发展

以下两件文献提供两种结构参照，比较范围是滤件的安装与维护动作。

R1 壶嘴侧固定框架支承滤件

解决的问题：在倒水路径中固定滤网，同时允许单独取出滤件。

结构与工作过程：US5672274A 的滤件位于壶嘴处，其两侧插入固定连接框架的槽内。维护时从壶嘴上部握住滤件顶缘向上拉，使底部凸起脱离锁止位置；连接框架仍固定在壶体。倒水时，水先经过框架开口和滤网，再由壶嘴流出。

变化及其原因：滤件与连接框架分别承担可拆维护和固定支承。

现有条件与限制：取出部位需要能被手握住，并留出向上拉出的空间。

E1 证据

R2 壶盖支承滤件，合盖时与内壁接合

解决的问题：倒水时过滤，并使滤件可以维护。

结构与工作过程：EP0676161A1 的滤件由壶盖刚性支承。合盖时，滤件周缘与壶嘴附近的内壁接合；打开壶盖时，滤件离开该接合位置。相关实施例允许将滤件从盖上拆下。倒水时，穿过滤网的水沿滤网与相对内壁之间的通路流向壶嘴。

变化及其原因：壶盖同时承担开闭和滤件支承；滤件的接合位置随开合动作改变。

现有条件与限制：若采用铰接壶盖，需留出滤件运动间隙，避免与壶体内壁碰撞。
